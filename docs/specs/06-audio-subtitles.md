# 06 配音、字幕與背景音樂（P8）

狀態：已實作　日期：2026-09-23

- TTS：`DoubaoTTS`（豆包語音 HTTP 接口，`TTS_APP_ID`、`TTS_TOKEN`）；未配置時退回 Mock 並在日誌警告。國際版 TTS 服務待確認（見 00 第 11 節）。
- 模板音頻方式 `native` 時傳 `generate_audio`，跳過 TTS；`none` 時無旁白音頻。
- 字幕：按標點斷句、每行 ≤16 字、去掉行尾逗號句號；時間軸按字數比例分配到旁白音頻時長；輸出 SRT 並存為素材。
- 背景音樂從素材庫選，循環鋪滿，用 sidechaincompress 在旁白出現時壓低，片尾淡出。
- 時長對齊：有旁白時片段時長 = 旁白 + 轉場 + 0.2 秒（影片短了延長最後一幀，長了裁剪），沒有旁白保持原長。
