# 14 介面改版：剪輯台（深藍・電影感）

狀態：已完成（2026-09-23，決定見文末；實作說明與偏差見「實作結果」）　日期：2026-09-23

## 背景

現在的前端幾乎是 Ant Design 預設樣式，看起來像通用後台。分鏡確認頁是一格格表單，看不到畫面，還外露 `video_long`、`keyframe`、調用記錄等內部術語。

設計稿：https://claude.ai/artifact/EWrDte7bnwqixkgSrjRmRn 的「第二版・剪輯台」頁，已確認方向。重點如下：
- 採用剪輯軟體的語彙：時間碼、場記板、分鏡表、剪輯時間軸，取代常見的 AI 產品樣板。
- 深藍底色，只用琥珀色一個強調色，加上膠片顆粒。
- 畫面為主角，加入克制的動畫。

## 目標

1. 全站換上新外殼與配色：頂部導航、深藍主題、字體、顆粒質感、動畫規範。
2. 三個核心畫面照設計稿重做，其他頁面用同一套語彙重排（決定 4）：
   - **片場**：首頁。
   - **開新片**：取代 4 步精靈。
   - **分鏡表**：待確認分鏡的任務詳情。
3. 用詞改成拍片語彙，一般使用者看不到模型代號與內部欄位。
4. 動畫尊重「減少動態效果」系統設定；分頁不在前景時暫停。

## 不做的事

- 淺色模式。
- 新增、刪除、重排分鏡：接口沒有，另立規格。
- 改動計價與任務狀態機。首幀預覽（決定 1）只新增一個不改變任務狀態的背景步驟。

## 設計

### 1. 用詞

| 現在 | 改為 |
|---|---|
| 任務列表（首頁） | 片場 |
| 新建任務 | 開新片 |
| 分鏡確認 | 分鏡表 |
| 產生分鏡／提交 | 寫分鏡 |
| 確認生成 | 確認開拍 |
| 重新生成腳本 | 重寫分鏡 |
| 成片庫 | 放映室 |
| 素材庫 | 素材 |
| 審核台 | 審核 |

任務狀態的新標籤：
- 寫分鏡中、待確認分鏡
- 生成中（REC 紅點）、合成中（MIX 音量條）
- 樣片完成、待審核、已通過、已退回
- 失敗、已取消、超出預算

裝飾用的英文等寬標籤（NOW SHOWING、IN PRODUCTION、SHOT 01 等）一樣放進 i18n。

### 2. 視覺規格

- **顏色**：色值以 CSS 變數定義在 `src/styles/tokens.css`。

  | 用途 | 色值 |
  |---|---|
  | 頁面底色 | `#070C18` |
  | 面板 | `#0B1322` |
  | 浮起面板 | `#111B2E` |
  | 細線 | `#1C2842`、`#26344F` |
  | 主文字 | `#E8ECF3` |
  | 次文字 | `#A6B0C3` |
  | 註記 | `#7F8BA1` |
  | 強調（琥珀） | `#F0A63A`；上面的文字用 `#1A0F00` |
  | 錄製中 | `#E5484D` |
  | 資訊 | `#7FA3E0` |

  所有文字對比 ≥ 4.5:1；註記色在最深的底色上約 5.6:1。
- **字體**：
  - 標題：思源宋體（Noto Serif TC）900。
  - 內文：思源黑體（Noto Sans TC）400／700（500 由瀏覽器就近取用）。
  - 時間碼與標籤：IBM Plex Mono 400／500。
  - 全部用 `@fontsource` 套件自帶，不連 Google Fonts：國內版部署連不到 Google，也不外洩使用者 IP。字體按 unicode-range 切片，只下載用到的字。
- **形狀**：圓角 2–4px，以細線分隔為主，少用卡片陰影。
- **質感**：全頁一層顆粒（256×256 灰階雜訊，`mix-blend-mode: overlay`，不透明度約 0.14），以 6 格步進抖動。
- **動畫**：時長與緩動統一定義在 `src/styles/motion.css`。

  | 動畫 | 用在哪裡 |
  |---|---|
  | 畫面緩慢推移 | 放映區、構圖預覽、監看畫面 |
  | 淡入上浮 | 區塊進場 |
  | 懸停放大與浮出按鈕 | 畫面卡片 |
  | 錄製中紅點閃爍、進度掃光 | 生成中的任務 |
  | 音量條跳動 | 合成中的任務 |
  | 打板開合 | 開新片的「寫分鏡」 |
  | 播放頭走動 | 分鏡表的時間軸 |
  | 底片片孔流動 | 片場的任務底片 |

  - `prefers-reduced-motion: reduce` 時，顆粒改為靜態，推移、流動與播放頭全部停止，只保留必要的狀態變化。
  - 分頁不在前景時（`visibilitychange`）暫停計時器與影片。

### 3. 技術做法

- 保留 Ant Design 6：`ConfigProvider` 用深色演算法加自訂色值（主色、底色、邊框、圓角、字體；主要按鈕文字改深色）。沒重做的頁面靠它自動換成新配色。
- 新增全域樣式 `src/styles/tokens.css`、`src/styles/motion.css`：CSS 變數、`@keyframes` 與少量工具 class（懸停放大、浮出、按鈕）。
- 新元件（`src/components/studio/`）：

  | 元件 | 內容 |
  |---|---|
  | `AppShell` | 頂部導航、即時時間碼、帳號選單（語言、用量、管理、登出） |
  | `Grain` | 全頁顆粒層 |
  | `PosterFallback` | 沒有畫面時的文字海報：片名、類型、顆粒 |
  | `StatusSlate` | 新樣式的狀態標籤 |
  | `FilmStrip` | 片場的任務底片 |
  | `Monitor` | 監看畫面：畫幅框、三分線、字幕安全區、取景角標、運鏡示意動畫、字幕 |
  | `Timeline` | 時間尺、畫面軌、聲音軌、字幕軌、播放頭；鏡頭可點選與鍵盤操作 |
  | `SlateForm` | 開新片的場記板表單 |

- 新 hooks：`usePrefersReducedMotion`、`useTimecode`（每 125ms 更新；背景分頁暫停）、`useAutosave`（800ms 防抖，失敗時顯示錯誤並可重試）。
- 路由：
  - `/` 由轉址到 `/jobs` 改為片場首頁。
  - `/jobs` 改名「全部任務」，沿用現有表格與篩選。
  - `/jobs/new` 換成開新片。
  - `/jobs/:id` 按狀態顯示分鏡表或任務詳情。

### 4. 頁面

**片場（`/`）**
- **放映區**：
  - 內容是最近 3 支有成片的任務（已通過或待審核），每 6 秒淡入切換。
  - 有成片時靜音循環播放（`muted playsinline`，捲入視窗才播）；只有封面時用封面加緩慢推移；都沒有時用文字海報。
  - 加上下黑邊與取景框角標。
- **快速開片列**：
  - 選類型（來自 `/templates`）、寫下想法，按「寫分鏡」。
  - 送出後建立任務並提交，再進入該任務。
  - 「完整設定」帶著已填內容進入開新片。
- **片場底片**：
  - 列出進行中與需要處理的任務，依更新時間排序：寫分鏡中、待確認分鏡、生成中、合成中、樣片完成、待審核、失敗、超出預算。
  - 畫面用 `preview_asset_id`，沒有就用文字海報。
  - 懸停時浮出主要動作：去確認、去審核、續跑。
  - 每 10 秒更新一次。
- **放映室精選**：最近 5 支成片，版面不等寬，點擊前往放映室。

**開新片（`/jobs/new`）**
- **單頁場記板**，欄位對應現有的 `JobCreate`：
  - 片名、類型（模板）、畫幅、長度（範圍依模板）、聲音方式（`tts_available=false` 時不顯示 TTS）。
  - 想法（topic）與補充說明（extra）。
  - 聲音風格、配樂、聲音一致、連續鏡頭。
  - 素材：商品圖、Logo、背景音樂，圖片轉短片還有首幀圖。
- **右欄**：
  - 構圖預覽：依畫幅以動畫變形，顯示已選的商品圖或首幀，三分線加字幕安全區。
  - 預估費用：呼叫新的 `POST /jobs/estimate`，參數變更後防抖 400ms 重算，顯示明細與佔單任務預算的比例。
  - 「先出樣片」開關。
- **「寫分鏡」**：打板動畫後建立並提交，跳到任務頁。欄位錯誤就地標示，不換頁。

**分鏡表（`/jobs/:id`，狀態為寫分鏡中或待確認分鏡）**
- **頁頭**：
  - 片名、狀態、規格摘要（類型、畫幅、鏡頭數、總長、聲音方式）。
  - 預估費用與預算，來自 `/jobs/{id}/estimate`，每次修改後重取。
  - 「重寫分鏡」（二次確認）與「確認開拍」：依 `allowed_actions`；超出預算時回 409，就地顯示。
- **監看**：
  - 播放頭所在鏡頭的首幀（沒有時用文字分鏡卡），配合運鏡示意動畫，並疊上旁白字幕。
  - 標示「預覽＝首幀＋運鏡示意，不是最終成片」。
  - 播放、暫停、上一鏡、下一鏡；時間碼顯示目前位置與總長。
- **鏡頭編輯**：
  - 欄位：畫面、旁白（字數與建議上限＝時長 × `chars_per_second`，超過轉紅）、說話者、音效、景別、運鏡、時長（± 按鈕，範圍依模型能力）、首幀（從素材替換）。
  - 自動儲存，顯示「已自動儲存」。
  - 改旁白時，監看字幕即時更新。
- **時間軸**：
  - 畫面軌按時長等比，點選即編輯該鏡。
  - 聲音軌：說話者與音效文字塊（分鏡階段沒有實際音訊，不畫假波形）。
  - 字幕軌：旁白。
  - 紅色播放頭。
- **調用記錄**：收進「技術細節」抽屜，只有管理員看得到。
- **寫分鏡中**：同一版面顯示進度與骨架畫面，完成後由 SSE 切換。

**其他狀態的任務詳情**
- 頁頭改成新樣式，時間軸顯示各鏡狀態：REC、完成、失敗與原因。
- 成片播放、審核結果、錯誤提示沿用現有面板，換上新配色。

**登入頁**：左邊是全幅靜幀加片名字卡與顆粒，右邊是表單。

**首幀預覽（決定 1，分鏡表內）**
- 每個鏡頭有「生成首幀預覽 · ¥0.25」按鈕，另有「全部生成」；已有首幀時改為「重新生成」。
- 送出後鏡頭顯示「首幀生成中」，完成後監看畫面與時間軸換成首幀。
- 失敗時在該鏡頭顯示原因並可重試；內容審核失敗照規則不自動重試。
- 開拍時直接沿用，不重複生成、不重複計費。

**其他頁面（決定 4）**
- **全部任務（`/jobs`）**：表格改為一列一支片，含預覽縮圖、狀態標籤、等寬字體的類型／畫幅／長度／費用。篩選改成頁籤加搜尋，保留分頁。
- **放映室（`/library`）**：
  - 成片藝廊：直式與橫式按比例混排，懸停時放大並出現播放鍵。
  - 點擊後開啟放映燈箱：深色遮罩、上下黑邊、播放器、片名與規格；已通過的片可下載。
  - 頁籤篩選類型，另有搜尋。
- **素材（`/assets`）**：
  - 上方是虛線的拖曳上傳條。
  - 素材以印樣表（contact sheet）網格呈現，每格有等寬編號與類型；頁籤篩選種類。
  - 點擊後右側抽屜顯示預覽、標籤與用途。
- **批量（`/batches`、`/batches/:id`）**：
  - 批量清單：每列一卷，含等寬批次碼、模板、分段進度條（依各片狀態上色）、各狀態數量。
  - 新增批量用場記板風格的對話框（CSV 上傳、並發數、樣片模式）。
  - 批量詳情：片場底片式的任務網格。
- **審核（`/reviews`、`/reviews/:id`）**：
  - 待審清單以片卡呈現，最早送審的排最前。
  - 審核頁：左邊是加黑邊的大監看播放器，右邊是「審核單」：檢查項、退回原因、通過／退回按鈕，下方是審核紀錄。
- **用量（`/usage`）**：
  - 頂部三個等寬大數字：今日、本月、每日預算剩餘。
  - 每日花費長條圖：琥珀色長條，等寬字體的座標。
  - 按模型、按使用者的表格附行內比例條。
  - 圖表照 dataviz 準則製作。
- **管理（`/admin`）**：頁籤改成等寬底線樣式；表格與表單換成細線格線，沿用現有功能。
- **404**：「NO SIGNAL」字卡：深藍色調的測試色條加顆粒，附回片場的連結。

### 5. 接口（API 契約 v1.3，只新增）

- `GET /jobs`：
  - `status` 可重複帶多個值（`?status=generating&status=composing`），只帶一個時行為不變。
  - 新增 `sort=created|updated`，預設 `created`；片場底片用 `updated`。
- `POST /jobs/{id}/scenes/{scene_id}/keyframe-preview`（首幀預覽）：
  - 請求：`{ force?: boolean }`；回應：`JobDetail`，狀態碼 202。
  - 只在任務為待確認分鏡、且有 `edit_storyboard` 權限時可用，否則回 409。
  - 鏡頭已有首幀且 `force` 不為 true 時回 409。
  - API 只把鏡頭狀態設為 `keyframe`、清除錯誤，並交給 Celery 的新步驟，不在請求內等待生成。
  - worker 呼叫現有的 `ensure_keyframe`（照常預算檢查、記賬、傳 safety_identifier 的規則），完成後鏡頭狀態回到 `pending`，並設 `needs_first_frame=true`；失敗時寫入鏡頭的 `error_kind`、`error_message`。
  - 首幀預覽還在生成時，「確認開拍」與「重寫分鏡」回 409：「首幀預覽還在生成」。
  - 開拍時 `ensure_keyframe` 看到已有首幀就直接沿用。
  - 需要擴充 `allowed_actions`：待確認分鏡時多一個 `preview_keyframe`。

- `JobSummary.preview_asset_id: string | null`：
  - 依序取封面、最後一個成功鏡頭的尾幀、第一個有首幀的鏡頭的首幀；都沒有時為 null。
  - 列表查詢一併取出，不新增 N+1 查詢。
- `POST /jobs/estimate`：
  - 請求：`{ template_id, target_duration_s?, ratio?, audio_mode?, draft_mode?, resolution? }`。
  - 回應：`{ total_cny, items: CostItem[], budget_per_job_cny, within_budget }`。
  - 依模板的鏡頭數把時長平均分到各鏡，沿用 `pipeline/estimate.py` 與 models.yaml 單價計算；不寫數據庫、不調用模型。
  - 參數驗證同 `POST /jobs`，不合法回 422。

不需要數據庫遷移。

### 6. 錯誤處理

- **自動儲存失敗**：欄位旁顯示「未儲存」與重試，不丟失輸入。
- **預估失敗**：顯示「暫時無法估算」，不阻擋送出（送出後在分鏡表仍會估算）。
- **影片自動播放失敗**（瀏覽器限制）：退回靜幀。
- **字體載入失敗**：退回系統字體（`PingFang TC`、`Microsoft JhengHei`、`serif`）。

### 7. 無障礙與效能

- 所有互動元素都是真正的按鈕、連結或輸入框，並有可見的琥珀色焦點框；時間軸鏡頭可用 Tab 與 Enter 操作。
- 動畫只用 `transform`、`opacity`；顆粒層 `pointer-events: none`、`will-change: transform`。
- 放映區影片 `preload="metadata"`，只在可見時播放；首頁圖片 `loading="lazy"`。
- 打包後 JS 增量目標 < 60 KB（gzip）；字體按需載入。

## 實作結果（2026-09-23）

- **接口多了兩個欄位（API 契約 v1.3，只新增）**：
  - `JobDetail.shot_duration_s { min_s, max_s }`：分鏡表時長 ± 的範圍，依目前階段的影片模型（樣片用 video_draft），規格要求「範圍依模型能力」但原本前端拿不到。
  - `JobSummary.runtime_s`：全部任務與放映室的「長度」，由列表既有的分鏡統計查詢一併取出，不增加查詢。
- **首幀預覽權限**：能看到任務但不能管理的審核者回 403（沿用代碼庫慣例，規格寫 409）；已退回的任務不開放首幀預覽，只在待確認分鏡時可用。
- **用量頁**：頂部三個大數字是「今日花費、近 N 天總花費、今日預算剩餘」；API 只回所選區間，所以用「近 N 天」取代「本月」。圖表依 dataviz 準則：單一琥珀系列（#C4802C，已用驗證腳本檢查深色表面的亮度帶與對比）、細線格線、峰值直接標值、懸停與鍵盤聚焦提示、表格檢視；沒有花費的日子補 0。
- **字體**：328 片 CJK `@font-face` 宣告（gzip 143 KB）改為動態載入、單獨成塊，首屏阻擋的 CSS 只剩自己的 13 KB。
- **測試環境一律以「減少動態效果」執行**（`test/setup.ts`），監看不自動播放、時間碼每秒更新，結果穩定；另有一個測試關掉這個設定，確認一般情況會自動播放。
- 分鏡表修改只存改過的欄位，後端更新其他欄位（例如首幀預覽完成）時不會被舊值蓋回；站內換頁時送出未存的修改，關閉分頁前提醒。

## 風險與待確認問題

### 風險

- 用詞大改後，使用者要重新熟悉；頁面內的說明文字會同步更新。
- 全頁顆粒與多個動畫在低階電腦上可能吃效能；已經限制為只用 `transform`／`opacity`，並提供減少動態效果的降級。
- Ant Design 深色主題在沒重做的頁面上可能有少數元件對比不足，E2E 截圖時一併檢查。
- 設計稿的畫面是程式生成的示意圖，正式版用真實的關鍵幀與成片；沒有畫面時的文字海報要做得夠好看。

## 決定（2026-09-23）

1. 分鏡表加「生成首幀預覽」（使用者手動觸發，每張約 ¥0.25，開拍時沿用）。
2. 首頁放映區靜音循環播放成片，只在可見時播放；減少動態效果時改成靜幀。
3. 字體用 `@fontsource` 自帶，不連 Google Fonts。
4. 其他頁面也在這一階段用新語彙重排，不只換配色。
